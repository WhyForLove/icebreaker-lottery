# 下一位 · 破冰抽签

一个用于破冰活动的头像随机抽签工具。无需安装，使用最新版 Edge 或 Chrome 即可运行。

## 在线使用

[打开网页版](https://whyforlove.github.io/icebreaker-lottery/)

在线版可以直接抽签，也可以临时读取你选择的本地图片文件夹。网页不会上传图片，但在线页面不能永久修改 GitHub 上的默认头像。

## 下载后使用

1. 点击仓库右上角的 **Code → Download ZIP**。
2. 解压下载的文件。
3. 使用 Edge 或 Chrome 打开 `web/index.html`。
4. 页面会自动载入项目自带的伙伴头像，可以直接开始抽取。

不需要安装 Node.js、Python、数据库或其他运行环境。

## 抽签操作

- 点击“下一位”开始或继续抽取。
- 点击“上一个”返回上一位伙伴。
- 点击未认识的伙伴席卡片，可以直接抽取该伙伴。
- 点击已经认识的伙伴，只会临时查看，不会重复加入抽取记录。
- PageDown、下方向键或右方向键：下一位。
- PageUp、上方向键或左方向键：上一位。
- 空格键：下一位。
- 刷新页面、重新开始或修改伙伴资料后，本轮记录会重置。

## 更换头像

打开右上角齿轮，可以临时更换图片文件夹。程序只读取以下图片类型，其他文件会自动跳过：

`JPG / JPEG / PNG / WebP / GIF / BMP / AVIF`

图片默认按文件名读取；没有单独填写昵称时，会使用去掉扩展名后的文件名作为昵称。

## 管理伙伴名册

下载到本地后，可以使用伙伴名册的完整功能：

- 按编号、昵称或文件名查询
- 批量添加伙伴并逐个填写昵称
- 修改昵称或头像
- 批量删除伙伴
- 拖拽、上移、下移或随机打乱顺序

第一次永久修改前，请在设置中点击“绑定头像文件夹”，然后选择：

```text
shared/defaults/头像
```

浏览器会要求一次文件夹读写授权。伙伴编号由当前顺序自动生成，增删或重新排序后仍会保持连续。

## 使用提醒

- 永久删除会同时删除本地图片文件，无法在页面中撤销。
- 浏览器可能在一段时间后重新询问文件夹权限，这是正常的安全机制。
- 头像来源于网络，仅用作学术交流，如有侵权，私信删除。
