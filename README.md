# 下一位 · 破冰抽签

一个用于破冰活动的头像随机抽签工具，提供网页版预览和 Windows Desktop V1.0.0。

## 在线预览

[预览网页版](https://whyforlove.github.io/icebreaker-lottery/)

在线页面主要用于预览界面、功能布局和大致的游戏框架，并不作为正式活动的可用版本。需要实际使用时，请下载下方的网页版或 Windows 桌面版，在本地更换头像和昵称后运行。

## 下载成品

普通使用者请到仓库的 [Releases](https://github.com/WhyForLove/icebreaker-lottery/releases) 下载成品，不需要编译源码：

- 网页版：下载 `icebreaker-lottery-web-v1.0.1.zip`，解压后使用 Edge 或 Chrome 打开 `web/index.html`。
- Windows 桌面版：下载 `icebreaker-lottery-desktop-v1.0.0-windows-x64.zip`，完整解压后双击 `下一位.exe`。

桌面版压缩包内只有 `下一位.exe` 和 `头像/`。两者必须放在同一目录；伙伴名册和图片的增删改会直接保存在这个 `头像/` 文件夹中。建议先保留一份原始压缩包作为备份。

## Windows 桌面版

Desktop V1.0.0 使用 Tauri 2，目前只支持 64 位 Windows，提供免安装便携版，不制作安装程序。桌面版复用网页版的抽签核心、界面和样式。

以下内容仅供需要修改源码的开发者使用。开发环境准备完成后，在 `desktop` 目录执行：

```text
npm install
npm run build:exe
```

构建结果为 `desktop/下一位.exe`。首次构建还会复制一份可编辑的 `desktop/头像/`，不会覆盖已有头像数据。生成的 EXE、头像副本、发布包和 Rust/Node 编译缓存均不进入 Git；完整说明见 `desktop/README.md`。

## 游戏说明

活动开始前，将伙伴名册中的图片更换为小组成员的头像或生活照片，并将昵称修改为对应的网络昵称或真实姓名。使用哪类照片、填写网络昵称还是真名，都可以由参与者自由决定。

可以参考以下游戏流程：

1. 抽到头像后，由头像对应的同学进行自我介绍。
2. 自我介绍结束后，由这位同学随机抽取下一位，或者主动选择一位尚未翻开的同学。
3. 在下一位同学正式介绍前，由上一位同学围绕头像进行观察和预测，尝试介绍这位同学。
4. 随后由下一位同学进行正式自我介绍，看看上一位同学的预测是否准确。
5. 按照以上方式继续抽取，直到所有成员都完成自我介绍。

## 抽签操作

- 点击“下一位”开始或继续抽取。
- 点击“上一个”返回上一位伙伴。
- 点击未认识的伙伴席卡片，可以直接抽取该伙伴。
- 点击已经认识的伙伴，只会临时查看，不会重复加入抽取记录。
- PageDown、下方向键或右方向键：下一位。
- PageUp、上方向键或左方向键：上一位。
- 空格键：下一位。
- 刷新页面、重新开始或修改伙伴资料后，本轮记录会重置。

## 更换头像

打开右上角齿轮，可以临时更换图片文件夹。程序只读取以下图片类型，其他文件会自动跳过：

`JPG / JPEG / PNG / WebP / GIF / BMP / AVIF`

图片默认按文件名读取；没有单独填写昵称时，会使用去掉扩展名后的文件名作为昵称。

## 管理伙伴名册

下载到本地后，可以使用伙伴名册的完整功能：

- 按编号、昵称或文件名查询
- 批量添加伙伴并逐个填写昵称
- 修改昵称或头像
- 批量删除伙伴
- 拖拽、上移、下移或随机打乱顺序

第一次永久修改前，请在设置中点击“绑定头像文件夹”，然后选择：

```text
shared/defaults/头像
```

浏览器会要求一次文件夹读写授权。伙伴编号由当前顺序自动生成，增删或重新排序后仍会保持连续。

## 使用提醒

- 永久删除会同时删除本地图片文件，无法在页面中撤销。
- 浏览器可能在一段时间后重新询问文件夹权限，这是正常的安全机制。
- 头像来源于网络，仅用作学术交流，如有侵权，私信删除。
